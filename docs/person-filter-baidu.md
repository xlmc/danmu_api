# 百度百科人物资料补充

开启 `BLOCK_DOMESTIC_CELEBRITIES` 后，系统先取得当前已匹配作品的 TMDB、Bangumi（动画）和维基百科人物资料。百度百科仅补充人物屏蔽名单，不参与作品搜索、平台选择或季集匹配。

- 已有演员名和中文角色名：跳过百度百科。
- 有演员名但整张中文角色表为空：保留已有演员名，补查中文角色名。
- 演员名和中文角色名均为空：补查两张名单。

触发依据是已有中文角色表是否为空，不是 TMDB 作品身份是否匹配成功；也不逐个判断演员是否缺少角色。

通过 `bkso.baidu.com` 读取当前作品网页，无需百度 API Key 或登录。校验作品名称、已知首播/上映年份、电影/剧集类型（已知时）和国产/港台制片地区。同名义项必须唯一匹配；明确季度标题不回退到基础作品名。只读取演员表中的名字，不读取人物介绍或遍历演员个人作品表。

沿用现有人物来源缓存和请求代理配置：可用名单缓存一天；请求失败或只取得演员名时五分钟后允许重试；刷新失败时保留已有可用名单。已有少量中文角色名即跳过补查，所以缓存状态不表示演员表逐条完整。

一次补查最多读取名称页及一个义项详情页，总等待上限八秒。遇到验证页、403、超时、身份不明确或演员表布局不支持时跳过补充，继续使用已有名单。网页结构和可访问性可能变化，部署环境需要能访问该域名。
