# NAS 精简版功能

- 官方平台、韩剧 TV（hanjutv）、人人视频（renren）搜索、分集及弹幕获取，支持分片与播放器协议。
- 规则匹配：文件名解析、严格标题/季号、年份判断、平台优先级、标题映射、季集映射及手动选择记忆。
- 内存搜索/弹幕缓存，本地查询快照与可选本地 Redis。
- 配置预览、日志、系统配置与缓存管理。
- 原有多源合并、偏移、过滤、输出格式和 Cookie 管理继续保留，本轮未扩大其删减范围。

已移除其余第三方来源（含 dandan；保留 hanjutv、renren）、360、本地弹幕、收藏/定时刷新、推送、Forward Widget、接口调试、弹幕测试、AI、Upstash、云部署管理、IP 黑名单及 TLS 校验关闭选项。

配置与 API 见 [configuration.md](configuration.md)，部署与迁移见 [deployment.md](deployment.md)。

## 首页真实统计

首页通过带 TOKEN 的 `GET /api/dashboard` 每 10 秒读取后端统计，接口禁用缓存，沿用现有 TOKEN/ADMIN_TOKEN 鉴权规则。

- 请求量：鉴权后的播放器搜索、详情、匹配、弹幕接口请求，包含失败响应；首页、统计轮询、日志和配置请求不计入。
- 弹幕返回量：成功整集/分段弹幕响应的实际条数，包含缓存响应；重复请求重复计数。非空响应次数不表示去重后的集数。
- 弹幕缓存命中率：播放器请求中的有效弹幕缓存命中次数除以查询次数，同一请求内同一个键只记录首次查询。未命中不等于实际回源次数。
- 耗时：最近最多 2048 个播放器请求在服务内部处理的平均耗时及 P95/P99，不包含客户端网络传输。
- 今日和趋势按服务端时区划分；在线时长取 Node.js 进程运行时间。峰值为自然秒内的播放器请求数。

统计仅保存在当前进程内，从本次服务启动开始，最多展示近 7 天；重启清零。启动前和未来的时段显示“未采集”，没有缓存查询时命中率显示“暂无查询”。接口失败时清空数值并提示错误，不继续显示过期数据。
