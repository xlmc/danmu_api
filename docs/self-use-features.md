# 自用调整说明

以下记录自用版保留的个人调整，不代表上游功能说明，也不表示所有播放器都兼容。

## 远程与本地剧名映射表

- 新增 `TITLE_MAPPING_TABLE_URL`：支持 GitHub 文件页、Gist、jsDelivr 和任意 TXT 直链。

- 首次下载后保存至 `.cache/title-mapping-remote.txt`；匹配时使用本地缓存，每天北京时间 05:30 自动更新，失败保留旧缓存并重试。

- `TITLE_MAPPING_TABLE`（本地表）优先于远程表；两者均支持标题、季数、年份，以及点号、空格、下划线等常见命名变体匹配。

- 远程表支持每行规则、分号分隔、`#` / `//` 注释、全角箭头和引号；适用于自动匹配、手动搜索、FongMi 与收藏。

- 管理端提供远程映射表手动刷新和独立日志查看。

## TOKEN 鉴权

- 默认使用 `TOKEN` 保护 API 和管理界面。

- 在受信任的内网环境中设置 `TOKEN_AUTH_DISABLED=true` 后，可直接访问根地址和管理接口，无需在 URL 中填写 TOKEN；该设置同时关闭所有 API 鉴权。

## 安全季集映射

`TITLE_MAPPING_TABLE` 兼容紧凑季号，例如 `诛仙S04->诛仙 最终季` 与 `诛仙 S04->诛仙 最终季` 等效。指定季度的规则优先于裸剧名；第 4 季规则不会作用于第 3 季。

### 自动匹配快速返回

`MATCH_SEARCH_BUDGET_MS=1500` 默认启用：先从已保存目录确认标题、年份、季度与明确集号，在最高优先平台组准确命中时直接复用剧集 URL。缺集或证据不足时搜索所有配置来源；预算后已有准确优先候选时提前返回，其他来源继续搜索、合并并写入完整缓存。部分结果不会覆盖完整缓存。明确手动偏好、集数偏移、AI 匹配以及带年份/类型/TMDB 目标限定的季集规则继续走完整搜索。

提前返回可能暂时缺少慢源的合并弹幕，已保存目录可能尚未收录新来源；若要求每次等待完整来源及合并，设置 `MATCH_SEARCH_BUDGET_MS=0`。手动搜索一直等待完整来源。没有准确候选时预算到期不会提前报空，而是继续原有回退流程。

主标题和别名均未明确季度时，可用同剧至少两个分集标题中的一致季号确认季度，例如腾讯的 `诛仙4_01`、`诛仙4_09`。不能依据“最终季”字样猜季号，也不会覆盖主标题/别名的明确季号或采用混季证据。

快速路径日志带 `[match-fast]` 和耗时。搜索预算只减少匹配等待，不是请求总超时；弹幕源站、人物过滤资料的首次加载等仍可能影响总耗时。

- `AUTO_MATCH_MAPPING_TABLE_URL` 读取 `Word/season-candidates.txt`，下载后保存在本机；匹配不等待远程网络，每天北京时间 05:30 更新。

- 本机 `AUTO_MATCH_MAPPING_TABLE` 优先于远程季集表。远程季集规则支持单点起始格式（如 `永生 S05E02 -> 永生 S01E58`），命中后按集数差值自动递增；需要反向转换时显式配置相反规则。

- 匹配采用成功即停止的瀑布顺序：本机手动选择 → 本机标题表 → 本机标题+季集组合 → 本机季集表 → 远程标题缓存 → 远程标题+季集组合 → 远程季集缓存 → 原始普通匹配。每一步必须实际得到作品和剧集才停止；远程表只读本机缓存，不在匹配请求中联网。

- 季集规则始终使用规范化标题精确触发，不受 `STRICT_TITLE_MATCH` 是否开启影响；普通未映射请求仍遵守原开关。

- 季集源规则支持可选 `{[group=ANi]}` / `{[group=ADWeb]}` 标记。文件名能解析出发布组时先按标题+季+集+组精确命中，再回退到标题+季+集通用规则；文件名没有发布组时不会要求组条件。发布组仅用于季集修正，画质/编码/音轨不会污染标题键。

- 目标中的 `{[tmdbid=...;type=...]}` 只用于内部候选限定，不写入播放器的匹配结果。季集转换不修改 `DANMU_OFFSET`、链接时间偏移或已有的手动集数偏好。

## 弹幕屏蔽词增强

- `BLOCKED_WORDS` 支持 `/正则/flags` 与纯文本词混用，兼容中英文逗号、逗号前后空格。

- 支持 `i`、`m`、`s`、`u` 标志；会自动避免 `g`、`y` 状态污染。

- 非法正则自动降级为纯文本匹配，并输出规则解析、命中数和拦截示例日志。

- 支持 `@人名` 条目并按语境分析匹配：三字及以上姓名按完整名称匹配；二字人名在独立姓名、标点或明确人物语境（"喜欢白鹿""白鹿老师""@白鹿"等称谓/指代）中命中，不会误伤"白鹿原"等同名词；同时启用严格版姓氏指代——"杨老师""欧阳导演""@杨"等显式指代命中，裸姓氏（如"我是杨"）不命中；普通纯文本词条的字面匹配语义不受影响。

- 支持 `地区:地区名` 条目并按地区语境匹配：仅命中"来自海南""海南网友""朝阳区"等明确地区语境，不屏蔽"海南鸡饭""朝阳升起"等同形词；地区名由用户自行填写；`地区:*` 或 `地区:全部` 启用内置预设地区名单（中国大陆省级行政区+地级行政区，不含港澳台）。

- `BLOCK_DOMESTIC_CELEBRITIES=true` 后通过 TMDB 获取当前国产/港台作品的中文演员名、角色名和明确的演员姓氏指代进行屏蔽；作品角色表中的完整角色名直接匹配（包含二字角色名）；演员完整名直接匹配，含二字姓名。需要可用的 `TMDB_API_KEY`，或能够代为认证的 TMDB 反代；动画角色名单同时合并 Bangumi 当前条目及动画前传、续集的角色资料，不因 TMDB 已有角色而跳过；匹配兼容简繁中文；查询失败或名单不完整时五分钟后允许重试，完整名单缓存一天。

- `BLOCK_DOMESTIC_REGIONS=true` 单独启用地区过滤，默认关闭；匹配明确地区语境，包括独立地区名、连续省市名、地区报到/围观/贺电、地区归属和方言称谓。保留非地区语境的普通词；未覆盖的新表达仍可能漏过滤。

- 不包含静态热门演员名单，不会按与当前作品无关的演员名全局过滤；演员/角色数据实时来自 TMDB 元数据。

## 收藏功能可用性检测

- 收藏列表接口返回 `favoriteSupported`，用于声明当前部署是否具备持久化收藏能力。

- NAS 部署挂载 `/app/.cache` 以持久化收藏；接口仍保留上游的能力检测，避免存储不可用时误报支持。

## 渐变彩色弹幕

- `DANMU_OUTPUT_FORMAT=danmux` 或查询参数 `?format=danmux` 返回 DanmuX v1 增强 JSON，同时保留播放器兼容的 `p/m` 字段。

- 带 `color_v2`、`colorV2`、`colorfulSrc` 等原生纹理字段的弹幕不加载纹理、不生成渐变效果，并按 `[dandan]` 来源输出。

- `GRADIENT_CHANCE` 渐变命中概率（0-100，默认 `0` 关闭）：`CONVERT_COLOR=color` 模式下，白色弹幕按该概率改为从渐变色带取色；颜色随弹幕出现时间平滑流转（60 秒循环），相邻弹幕颜色渐变过渡。

- `GRADIENT_COLORS` 渐变色带：可填皮肤名（`bilibili` 粉→蓝 / `sweet` 粉紫 / `cyber` 电竞 / `sunset` 日落 / `ocean` 海洋 / `mint` 薄荷 / `rainbow` 彩虹七色）或自定义十进制颜色值逗号分隔串（至少 2 个），默认使用 `default` 皮肤。

- `DANMUX_GRADIENT_STOPS` 可用 JSON stops 覆盖皮肤颜色，`DANMUX_GRADIENT_ANGLE` 设置线性渐变角度；错误 JSON 会安全回退到当前皮肤。

## 匹配兼容约定

- 同步上游后继续保留映射瀑布、发布组规则、标题/别名过滤和严格季号保护。
- 上游兜底策略会在没有同季候选时尝试其它季；自用版不将明确的其它季同集号作为普通兜底。显式映射和已有跨季换算逻辑保持独立。
- 版本与发布状态统一见 [自用版版本说明](../SELF_USE_CHANGELOG.md)。

### 昵称与日期屏蔽

- 当前作品角色名单自动派生昵称：多字名去姓，单字名匹配阿、子、儿、哥、姐称呼；昵称直接匹配，同名普通词也会命中。仅从已取得的角色资料生成，不从弹幕推断。
- `BLOCK_DATES=true` 屏蔽包含有效完整年月日或时间的弹幕，支持点号、横线、斜线、中文年月日，以及时:分、时:分:秒（含全角冒号）。默认关闭，普通小数、无效日期和带 v 前缀的版本号保留。

- 人物资料增加维基百科补充：只查询当前作品页面，不遍历演员作品表。核对名称与首播/上映年份，只从演员/角色表格提取姓名、角色和表中列出的化名，不从剧情正文推断人名。页面缺失或无明确表格时仍可能缺少角色。
- 维基百科使用公开 MediaWiki API，沿用用户配置的适用代理，单次请求最长五秒；限流时遵守 Retry-After。日志保留来源页面与修订号。资料依据社区编辑内容，不保证覆盖所有角色；使用规则见 https://www.mediawiki.org/wiki/API:Etiquette ，内容许可见 https://zh.wikipedia.org/wiki/Wikipedia:著作权 。
- 播放请求并行加载弹幕和人物资料，各人物资料来源并行补充；全部过滤完成后返回。原始弹幕缓存仍支持关闭屏蔽后恢复，作品人物名单与在途请求继续复用。

### 过滤入口与人物资料缓存

- 剧集 ID、URL、本地弹幕、分段弹幕以及弹幕缓存命中均执行演员、角色、地区和日期时间过滤。只使用当前作品的演员、角色及派生昵称；地区词典全局复用，并保留非地区语境。
- 直接 URL 请求优先从已匹配的剧集确定作品；无法确定时可传 `animeTitle` 查询参数（包含年份可减少同名歧义）。同一 URL 对应多个作品时跳过人物名单，仍执行地区和日期时间规则。分段列表携带 `animeTitle`、`sourceUrl`，播放器应原样回传；旧播放器省略新字段时可复用本次服务已登记的分段作品关系。
- TMDB 作品身份、演员表、Bangumi 角色表和维基百科表格分别缓存，有效期 24 小时。过期的有效资料立即参与过滤，并在后台刷新；失败或部分资料五分钟后允许重试，只刷新需要更新的来源，失败不会清空有效旧名单。无可用名单的首次请求仍需等待资料获取。
- Node/Docker 将来源资料保存到 `.cache/person-sources-v1.json`，重启后复用，需保留 `.cache` 挂载。缓存键对 API 密钥及代理配置做哈希；配置变化时重新获取。其他部署使用内存缓存。来源资料仍可能不完整，缓存不会自动补出资料源没有收录的角色。

- 人物查询遇到“第 N 季”、Season N、SNN 或最终季后缀时，精确名称失败后可查询同名 TV 系列，必须核对对应季度及季度年份；最终季使用 TMDB 已登记的最高正季号，不混用同名电影。经验证后补充来源使用系列名称及系列首播年份。若资料平台尚未登记正确季度，则仍可能无法匹配。TMDB 失败时补充来源独立核对原始作品标题、年份，成功名单继续参与过滤。
